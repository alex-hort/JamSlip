# 🎵 JamSlip

> An AI-powered iOS music app that discovers, streams, and recommends music tailored to you — built with SwiftUI and Google Cloud Platform.

JamSlip is a native iOS application that delivers a personalized music discovery and playback experience. Its recommendation engine is powered by the **Gemini API**, which analyzes each user's listening history to suggest new songs, while a containerized microservices backend on **Google Cloud Platform** handles authentication, audio streaming, and real-time data.

## ✨ Features

- 🔐 **Sign up & log in** with email or Google Sign-In (Firebase Authentication)
- 🔎 **Explore music** with filters by genre, artist, and popularity
- ▶️ **Built-in audio player** with playback, seek, and volume controls (AVFoundation)
- 🤖 **AI-powered recommendations** generated by the Gemini API based on your listening history
- 📂 **Personal playlists** synced in real time with Firebase Realtime Database
- 🔔 **Push notifications** for new song uploads, handled by serverless functions

## 🛠️ Tech Stack

### iOS App
- **Language:** Swift 5.9
- **UI framework:** SwiftUI
- **Audio playback:** AVFoundation
- **Networking:** URLSession + Codable (REST)
- **Auth:** Firebase Authentication SDK for iOS

### Backend (Google Cloud Platform)
- **Cloud Run** — containerized backend microservices (auth, streaming, recommendations), serverless & auto-scaling
- **Cloud Run Functions** — event-driven processing (audio uploads, push notifications, metadata validation)
- **App Engine** — admin backend with automatic scaling
- **Cloud Storage** — audio files (mp3/flac), cover art, and static assets
- **Firebase Realtime Database** — playlists and player state in real time
- **Gemini API / Vertex AI** — music recommendation engine
- **Cloud Tasks** — async processing queue (audio transcoding, emails)
- **Secret Manager** — secure storage for API keys and tokens
- **Cloud Build + Artifact Registry** — CI/CD pipeline: build, test, and deploy on every push to `develop`
- **Cloud Logging & Monitoring** — centralized logs, dashboards, and alerts

## 🏗️ Architecture

JamSlip follows a **containerized microservices** pattern:

```
┌─────────────┐   HTTPS/REST   ┌──────────────────────────────┐
│  iOS App    │ ─────────────► │        Cloud Run             │
│  (SwiftUI)  │                │  auth │ streaming │ recs     │
└─────────────┘                └───────┬──────────┬───────────┘
                                       │          │
                     ┌─────────────────┤          ├──────────────┐
                     ▼                 ▼          ▼              ▼
              Cloud Storage    Firebase RTDB   Gemini API   Cloud Tasks
              (audio/assets)   (playlists)     (AI recs)    (async jobs)
```

Each microservice is packaged in its own **Docker** image, stored in Artifact Registry, and deployed automatically by Cloud Build on every commit.

## 🚀 Getting Started

### Prerequisites
- macOS with **Xcode 15+**
- iOS 17+ device or simulator
- A Firebase project with Authentication and Realtime Database enabled
- A Google Cloud project with the required APIs enabled

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/alex-hort/JamSlip
cd jamslip

# 2. Open the project in Xcode
open JamSlip.xcodeproj

# 3. Add your Firebase config
#    Download GoogleService-Info.plist from the Firebase Console
#    and drag it into the Xcode project.

# 4. Build & run (⌘R) on a simulator or device
```
